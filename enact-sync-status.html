The consolidation promised a tool a build cannot deliver

Every consolidated family got an inventory row claiming Always, while the email family's members sit behind tools-external. A default build therefore promised a tool it could not deliver, and upstream's own gate — every compiled row must register under the maximal config — failed on it. The consolidation offered memory to runs that had removed it

The scope filter drops the persistent memory tools by name, and a family's own name is not one of its members'. A cron run with uses_memory = false was therefore still offered the memory family, whose description names every member and whose actions call the very tools the run was told to drop. This was behaviour, not only a test: the run was offered memory access it had been denied. A family is now offered only while at least one of its members is, and the overlay gate states that rule.
